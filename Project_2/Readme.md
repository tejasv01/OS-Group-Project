## 📌 Project Overview
This project implements a complete **Multi-Level Feedback Queue (MLFQ)** CPU scheduler in the `xv6-riscv` kernel. The default xv6 Round-Robin scheduler is replaced with a dynamic, 4-tier priority feedback scheduler that optimizes interactive responsiveness, awards compute-heavy jobs appropriate time quanta, and prevents starvation through periodic priority boosting.

## 🚀 Quick Start: Running the Demonstrations

### 1. Continuous 5-Process Queue Transfer Tracer
Demonstrates how 5 distinct processes with different workloads interchange between queues $Q0 \rightarrow Q1 \rightarrow Q2 \rightarrow Q3$ with **constant, invariant PIDs (PIDs 4, 5, 6, 7, 8)**:
- **Worker A (Heavy CPU-Bound):** Continuous computation without yielding $\rightarrow$ Demotes to Q3.
- **Worker B (Medium Compute):** Moderate compute bursts with periodic yields $\rightarrow$ Settles in Q2.
- **Worker C (Interactive):** Short bursts with frequent voluntary yields $\rightarrow$ Retains Q0/Q1.
- **Worker D (Short I/O):** Periodic short sleep via `pause(2)` $\rightarrow$ Wakes in Q0 with 0 tick penalty.
- **Worker E (Long I/O):** Long sleep via `pause(6)` $\rightarrow$ Demonstrates I/O sleep tick neutrality.
```bash
python3 run_trace.py
```
*(Or inside xv6 shell: `$ mlfq_trace`)*

## ⚙️ MLFQ Scheduling Policy Specification

| Queue Level | Priority | Time Quantum | Scheduling Algorithm |
|:---:|:---:|:---:|:---|
| **Q0** | Highest Priority | 1 timer tick (~100 ms) | Round-Robin |
| **Q1** | Second Priority | 2 timer ticks (~200 ms) | Round-Robin |
| **Q2** | Third Priority | 4 timer ticks (~400 ms) | Round-Robin |
| **Q3** | Lowest Priority | 8 timer ticks (~800 ms) | Round-Robin |

- **Top-Priority Entry:** All newly created processes enter at queue **Q0** with 0 consumed ticks.
- **Strict Priority Selection:** Scheduler always selects runnable processes from the highest non-empty queue.
- **Quantum Demotion:** When a process fully exhausts its queue quantum, it is demoted ($Q0 \rightarrow Q1 \rightarrow Q2 \rightarrow Q3$).
- **Voluntary Yield Retention:** A process that relinquishes the CPU via `yield()` or `sleep()` before exhausting its slice retains its priority.
- **Periodic Priority Boost:** Every **40 ticks** (`BOOST_INTERVAL`), all processes are boosted back to **Q0** to prevent starvation. Cumulative historical tick statistics are preserved.

## 🛠️ Building and Compiling from Source

To compile the kernel and disk image cleanly:
```bash
cd xv6-riscv
make clean
make -j4
make fs.img
```

To run xv6 manually under QEMU:
```bash
make qemu CPUS=1
```

Inside the xv6 shell, the following diagnostic commands and tests are available:
- `mlfq_trace`: Continuous 5-process queue interchange tracer (Workers A, B, C, D, E).
- `ps_mlfq`: Displays process table with MLFQ priority and per-queue tick counters.
- `test_init_pri`: Verifies initial priority assignment (Q0) on process creation.
- `test_cpu`: Verifies compute-bound demotion through Q0 -> Q1 -> Q2 -> Q3.
- `test_yield`: Verifies priority retention across 50 voluntary yields.
- `test_sleep`: Verifies that sleeping time is not counted as CPU execution time.
- `test_boost`: Verifies periodic priority boost from Q3 back to Q0.
- `test_compete`: Verifies Round-Robin fairness among competing processes.
- `test_stress`: Verifies concurrency, spinlocks, and kernel stability under load.
- `test_getpinfo`: Verifies pointer security and data extraction for the `getpinfo()` syscall.
